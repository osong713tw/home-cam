# 📹 家用監視器（iPhone 當鏡頭、掃 QR Code 監看）

用一支 iPhone 當監視鏡頭，其他 iPhone／iPad 只要掃描鏡頭畫面上的 QR Code，就能即時監看。
不需要安裝 App，也不需要電腦，整個系統是一個放在 GitHub Pages 上的網頁。

## 功能

- 📷 **鏡頭端**：前後鏡頭切換、畫質 480p／720p／1080p、麥克風開關、省電黑畫面、鏡頭命名
- 📺 **監看端**：分割畫面（最多 6 支鏡頭），點一下放大，可以聽聲音
- 🏃 **移動偵測**：警示音加紅框閃爍、靈敏度 1～10、移動紀錄（記錄時間與鏡頭）
- 🔐 **安全**：QR Code 內含 128 位元隨機密鑰，監看端必須通過 HMAC 驗證，鏡頭才會送出影像
- 🔁 **自動重連**：鏡頭重新整理、網路短暫中斷後會自動恢復

## 運作原理

```
 鏡頭 iPhone ──(1) 配對訊息──▶ PeerJS 公用配對伺服器 ◀──(1)── 監看 iPad
      │                                                         ▲
      └────────(2) 影像／聲音：在家中 Wi-Fi 內直接傳送 ─────────┘
```

1. 配對伺服器（免費的 0.peerjs.com）只負責讓裝置「找到彼此」，只交換很少量的連線資訊。
2. 影像和聲音透過 WebRTC 加密，在裝置之間直接傳送，**不會上傳到雲端**。
3. 配對伺服器只看得到房間代號（由密鑰雜湊而來），看不到密鑰本身。

## 部署到 GitHub Pages（只需做一次）

1. 登入 <https://github.com>，點右上角 **＋ › New repository**。
2. Repository name 填 `home-cam`（任意名稱都可以），選 **Public**，按 **Create repository**。
3. 在新的儲存庫頁面點 **uploading an existing file**，把這個資料夾裡的**所有檔案和子資料夾**拖進去
   （包含 `css`、`js`、`vendor`、`icons` 資料夾），再按 **Commit changes**。
   > 用電腦瀏覽器拖曳最方便。手機的 Safari 無法上傳資料夾，可以請 Claude 直接幫你推送。
4. 到儲存庫的 **Settings › Pages**，Source 選 **Deploy from a branch**，Branch 選 **main**、資料夾選 **/ (root)**，按 **Save**。
5. 等 1～2 分鐘，網址會是：`https://你的帳號.github.io/home-cam/`

## 使用方式

1. **鏡頭**：在要當鏡頭的 iPhone 上用 **Safari** 開啟上面的網址 › 「📷 這台當鏡頭」› 開始拍攝 › 允許相機與麥克風。
2. **監看**：用其他 iPhone／iPad 的「相機」App 掃描畫面上的「📺 監看」QR Code › 開始監看。
3. **加鏡頭**：用另一支 iPhone 掃描「📷 加入其他鏡頭」QR Code，監看端會自動多出一個畫面。
4. 小技巧：在 Safari 點 **分享 › 加入主畫面**，之後就能像 App 一樣一鍵開啟。

## ⚠️ iPhone 當鏡頭的注意事項

- **必須停留在拍攝頁面，螢幕不能鎖定**。這是 iOS 的限制：網頁一進入背景，相機就會被關閉。
  - 接上充電器
  - 「設定 › 螢幕顯示與亮度 › 自動鎖定」設為**永不**
  - 想省電可以用「🌙 黑畫面」，畫面全黑但仍在拍攝，連點兩下回到畫面
- 不要用 LINE、Facebook 等 App 的內建瀏覽器開啟，請用 Safari。
- 移動偵測在監看端計算，**監看頁面必須開著、在畫面上**才會發出提醒。
- 每支鏡頭最多同時 4 台監看裝置（避免拍攝手機過熱）。

## 沒有 Wi-Fi 時（4G／5G）

| 方式 | 是否可行 | 流量 |
|---|---|---|
| 一支手機開**個人熱點**，其他裝置連上熱點 | ✅ 最推薦，等同在同一個 Wi-Fi | 幾乎不花流量（影像在熱點內傳送） |
| 鏡頭和監看端各自用 4G／5G（遠端監看） | ⚠️ 可能可以，不保證 | 720p 約每小時 0.8 GB |

各自用行動網路時，電信業者常常會擋掉兩台手機直接連線。這時影像會經過 PeerJS 內建的免費公用中繼伺服器（TURN）轉送，但速度與穩定性都不保證。
如果需要穩定的遠端監看，可以在 `js/config.js` 設定自己的 TURN 伺服器（例如 Cloudflare 或 Metered 的免費方案）。

## 常見問題

- **一直顯示「正在尋找鏡頭」**：確認鏡頭 iPhone 停在拍攝頁面、狀態是綠燈「上線中」；也可以在監看端重新掃描 QR Code。
- **想讓舊的 QR Code 失效**：在鏡頭端「⚙️ 設定 › 建立新房間」，所有裝置都需要重新掃描。
- **聽不到警示音**：點監看端的 🏃 › 「測試警示音」；iOS 16.4 以前的版本請關閉靜音鍵。
- **配對伺服器暫時故障**：已經連上的畫面會繼續播放；新連線要等伺服器恢復後自動重連。
